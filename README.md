# Sitema bancário em C#

Projeto desenvolvido para praticar lógica de programação utilzando C#

## Funcionalidades

- Consular saldo
- Realizar depósitos
- Realizar saques
- Visualizar extrato
- Validação de valores

# Tecnologias 

- C#
- .Net
- Visual Studio 2022

# Objetivo

Projeto criado com intenção de melhorar minhas habilidades na programção e estudo em Sistema de Informação para praticar decição, laços de repetição e controle de variaveis
